# Dashboard (Next.js)

Scenario Lab, 3D live twin, live analytics and model cards for the airport digital twin.
See the [main README](../README.md) for the full project.

```bash
npm ci
npm run dev            # http://localhost:3000
```

| Script | What it does |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` / `npm start` | Production build and server |
| `npm run build:static` | Static export to `out/` (GitHub Pages) |
| `npm run lint` | ESLint (Next.js core-web-vitals + TypeScript rules) |
| `npm run typecheck` | Route type generation + `tsc --noEmit` |
| `npm test` | Vitest suite for the in-browser simulation engine |

## Configuration

Copy `.env.example` to `.env.local`:

- `NEXT_PUBLIC_API_URL`: FastAPI base URL. Leave empty to run scenarios in the browser.
- `NEXT_PUBLIC_BASE_PATH`: sub-path for project-site hosting, e.g. `/airport-digital-twin-simulation`.

`data/model-artifacts.json` is generated by `python -m ml_models.export_artifacts` and carries the
process parameters, model metrics, satisfaction response surface, delay distribution and traffic forecast.

`patches/` holds a small fix for `@react-three/drei`'s `<Html>` component under React 19 (deferred root
unmount). It is applied automatically by `patch-package` on install.
